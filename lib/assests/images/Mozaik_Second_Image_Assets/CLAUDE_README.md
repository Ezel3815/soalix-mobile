# Mozaik Icon Assets — extracted from the second generated board

These PNGs are crops of the **exact visual icon tiles shown in the second Mozaik icon-system image**. Use the full reference image as the visual source of truth.

Important:
- These are intentionally not generic Lucide/Material icons.
- Preserve the soft mint/cream surfaces, rounded tiles, gradients, shadows, and Mozaik geometric character.
- Keep the colored/pastel subject icons visually prominent.
- For production, these PNGs can be used immediately as image assets; if scalable vectors are required, use them as the reference for a vector redraw rather than substituting a generic icon set.
- `manifest.json` maps every asset to its section and filename.
